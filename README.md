# Jogo de Memória Acessível 🎮

Um jogo web educacional de memória desenvolvido com foco em **acessibilidade e inclusão**, seguindo as diretrizes [WCAG 2.1](https://www.w3.org/WAI/WCAG21/quickref/) (Nível AA).

## ♿ Princípios de Acessibilidade

Este projeto implementa os 4 pilares WCAG:

- **Perceptível**: Conteúdo legível, alto contraste, suporte a leitores de tela
- **Operável**: Navegação total por teclado, sem armadilhas de teclado
- **Compreensível**: Linguagem clara, instruções explícitas, consistência
- **Robusto**: HTML semântico, compatibilidade com tecnologias assistivas

## 🚀 Recursos

- ✅ Suporte completo a navegação por teclado
- ✅ Compatibilidade com leitores de tela (ARIA)
- ✅ Alto contraste de cores (WCAG AA)
- ✅ Feedback visual e sonoro
- ✅ Modo foco facilitado
- ✅ Responsivo em todos os dispositivos
- ✅ Dificuldades ajustáveis

## 📋 Tecnologias

- **HTML5** com semântica acessível
- **CSS3** com foco em contraste e responsividade
- **JavaScript** com boas práticas de acessibilidade

## 🎯 Como Jogar

1. Clique ou use `Tab` para navegar pelas cartas
2. Use `Enter` ou `Espaço` para revelar uma carta
3. Encontre os pares combinando as cartas
4. Complete o jogo em menos movimentos possível!
